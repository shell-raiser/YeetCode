Creates a token for this extension only (OAuth Device Flow — no PAT needed). Requires an OAuth App Client ID; get one at github.com/settings/applications/new and enable Device Flow on it.

GitHub's OAuth sign-in requests access to all your repositories — the GitHub API does not let an OAuth app be limited to a single repo. YeetCode only ever reads from and writes to the repository configured below in "GitHub Repository". If you prefer to grant access to just that one repo, create a fine-grained Personal Access Token with access to it only and paste it into the token field instead.
